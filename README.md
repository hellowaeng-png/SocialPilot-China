# SocialPilot China\n\nWindows desktop application prototype.\n\n## Current scope\n- Local SQLite database stored under the current Windows user's Local AppData folder.\n- Basic account, content, advertisement and plan records.\n- Database backup.\n- Windows installer is built by GitHub Actions.\n\n## Important limitation\nThis prototype does **not** log into Weibo, publish posts, run scheduled publishing jobs, or bypass platform security controls. Real publishing must use a platform-authorized integration.\n\n## Build\nRun the **Build Windows Installer** workflow in GitHub Actions. Download the `SocialPilotChina-Windows-Installer` artifact after a successful run.\n
